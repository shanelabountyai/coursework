### Catalog and graph

| # | Decision | Why |
|---|----------|-----|
| D-11 | **Prerequisites are a closed-vocabulary expression** (brief G1): `null`, a code, `{"all":[…]}`, `{"any":[…]}`; children of a group are codes or groups of the other kind; depth ≤ 2; no free-form text, no minimum-grade conditions (seam: O-3). Stored as JSON on the course row, validated on publish. | Adjuster's rules-as-data; depth 2 covers "(A and B) or D" and "A and (B or C)", which is every pattern in a real catalog the author has seen **[verify]** |
| D-12 | **Edges are structural and cycle detection is structural** (G2, G3): every leaf is an edge whether under ALL or ANY; any strongly connected component is `REJECT:CYCLE`, including a self-reference (a 1-cycle) and an ANY whose other branch is satisfiable (E-06). The reported path is the lexically-smallest-start BFS cycle inside the component; components listed by smallest member. | An unsatisfiable branch is a catalog error, not an option; a stated path order lets TypeScript and Python be compared byte for byte |
| D-13 | **Topological order ties break lexically by course code** (G4), drafts and retired included. | One order to compare |
| D-14 | **Publish-time checks in stage order** expression → unpublished prerequisite → cycle; every error reported; headline is the first (G5). A PUBLISHED course may not require a DRAFT or RETIRED course; retiring a course three published courses require fails naming all three (E-12). Draft courses may reference anything that exists. | Authors fix all errors in one round, and the headline code is deterministic |
| D-15 | **Catalog versions are immutable and content-hashed** (V1): SHA-256 of canonical JSON of `{certificates, courses, equivalencies}`; an accepted edit creates a new version. In Phase 2 the version table is append-only (trigger). A learner's enrollment and each completion event record the version id (V2). | Adjuster's `RuleSetVersion`; "which rules decided this" is always answerable |
| D-16 | **Leaf satisfaction precedence** `PASSED` → `EQUIVALENT:<by>` → `WAIVER:<reason>` (G6). Equivalencies are catalog data; waivers are learner data with a closed reason set (`TRANSFER_CREDIT`, `PLACEMENT_TEST`, `INSTRUCTOR_WAIVER`, `PRIOR_LEARNING`), a granted day and a grantor. A FAIL satisfies nothing. | Every satisfied leaf carries its reason, so a path view can say *why* a course is not needed |
| D-17 | **"Minimal missing set"** = fewest codes under the expression; ANY picks the child with the fewest missing, ties by lexicographic comparison of the sorted lists (G7). Leaf-count, not depth. | Deterministic and explainable in one sentence; depth-aware "closest to done" is O-4 |
| D-18 | **Shortest path is exact** over all ANY-branch combinations in the upstream cone, fewest courses, ties lexical, output in G4 order (G8). The oracle asserts ≤ 4,096 combinations per query; `cat-v1`'s maximum is 16. | Greedy per-group choice is wrong on the `CERT-DATA-ADV` 9-vs-9 tie; the cone is small enough to enumerate |
| D-19 | **An edit that retroactively blocks an in-progress learner is reported, never blocked** (G9): `GRANDFATHERED` flag with the new missing set; the enrollment stands under the version it was evaluated against. | Changing the rules on someone mid-course is a policy call for a person, surfaced as a number on the publish screen |

### Gradebook

| # | Decision | Why |
|---|----------|-----|
| D-23 | **Scores are integer hundredths of a percent; weights are basis points summing to 10000; intermediate arithmetic is exact rationals** (Python `Fraction`; TypeScript `{num: bigint, den: bigint}` with a tiny `Rational` module owned here) and the final grade is rounded **half-up, once** (S2, S8). No float under `src/grades/` (lint). Pass is decided on the rounded value. | GS-13/14: 6999.5 passes and 6999.2 fails, and a float path makes that non-reproducible |
| D-24 | **Late penalty** = `min(days_late, max_days) × per_day_hp` subtracted from the score, floored at 0 (S3). Multiplicative penalties are not offered. | Subtractive is what the trap "goes negative" is about, and the floor is stated |
| D-25 | **Missing work** per scheme flag: `ZERO` counts as 0 with the possible points; `EXCLUDE` removes the assignment from both sums (S4). Missing extra credit is always excluded and never flagged. | Both policies exist in real schools; one flag, no third option |
| D-26 | **Drop-lowest-N ties: the lexically smaller assignment code is dropped** (S5). | Deterministic; GS-03 shows it changes the grade (9233 vs 9250); "most favorable to the learner" is O-5 |
| D-27 | **An empty category's weight is redistributed proportionally** over non-empty categories (S6); all empty → 0 with `NO_GRADED_WORK`. A category with no assignments at all (DAT-102's Project) and one emptied by `EXCLUDE` (WRT-101's Participation) are treated the same. | The alternative (empty category scores 0) turns an unassigned project into a 20-point penalty, GS-09 |
| D-28 | **Extra credit** adds to the category numerator only and the final gain is capped at `extra_credit_cap_hp` (S7), then the final is clamped to [0, 10000]. | A cap stated on the final grade is the only one a learner can check |
| D-29 | **Letter bands are scheme data** (S9), first band with `min_hp ≤ final_hp`. | No letter logic in code |

## Open — need Shane's call (defaults are in force until changed)

| # | Question | Default | Why it's open |
|---|----------|---------|---------------|
| O-1 | Should an ANY branch that forms a cycle be allowed when another branch is acyclic (E-06)? | **No** — `REJECT:CYCLE` (D-12) | Some registrars model "or an equivalent later course" this way; it makes eligibility depend on evaluation order |
| O-2 | Grandfathering (D-19): flag only, or also pin the learner's enrollment to the old version automatically? | Flag only; the enrollment already carries its version (V2) | Auto-pinning is convenient but hides the policy decision |

| O-5 | Drop-lowest tie: lexical code (D-26) vs. most favorable to the learner | Lexical | Favorable-to-learner is the policy most schools would state if asked; it is also the one that needs the arithmetic to decide the tie |
| O-6 | Empty-category redistribution (D-27) vs. "empty category contributes 0" vs. "grade withheld until the category has work" | Redistribute | Withholding is the most honest for a cohort mid-term; redistribution matches what a final transcript does |

| O-8 | Rounding at the category level for display | Never for computation; display may show two decimals of the exact rational | A learner who sees 69.99 on screen and FAIL at 70.00 will ask; the screen must show the exact fraction on request |
